# Kendall Capital — stakeholder demo access

Give **Clark Kendall** (or any stakeholder) signed-in access to the **Kendall Capital** business Space so they can open Files and Ask Gideon themselves.

## What changed

Business (and nonprofit) Spaces can invite collaborators — same invite flow as client Spaces.

## Owner prep (you)

1. Confirm Kendall Capital has analyzed sources:
   - Form ADV Part 2A
   - Form CRS (if available)
   - Optional: website import from `kendallcapital.com`
2. Smoke-test in that Space:
   - *How are fees described?* → ADV fee tiers + source
   - *What do we know about Kendall Capital?* → grounded summary
3. Invite Clark:
   1. **Settings → People & spaces**
   2. Open **Kendall Capital** → **⋮ → Manage access**  
      (or go to `/settings/profiles/{kendallCapitalId}/collaborators`)
   3. Enter Clark’s email
   4. Access level: **Edit** (recommended for demo — full Files + Ask Gideon)
   5. **Send invite**
   6. If email doesn’t arrive, copy the invite link from the success UI and send it manually

## What Clark does

1. Open the invite link (`/invite/...`)
2. **Create an account** or **Sign in** with the **same email** that was invited
3. Accept the invite
4. He lands in Kendall Capital and can:
   - Browse **Files** (ADV, CRS, website pages)
   - Use **Ask Gideon** with questions like:
     - What do we know about Kendall Capital?
     - How are fees described?
     - What services are described?
     - What does the Form CRS cover?

## Role notes

| Role | Best for | Sees |
|------|----------|------|
| **Edit** | Live stakeholder demo | All Space documents + Ask Gideon + can upload |
| **View** | Read-only tour | Only documents marked **Shared** under “What clients can see” + Ask Gideon on those |

For Clark’s first demo, use **Edit**.

## Scope

- Invite is for **Kendall Capital only** — not sibling Spaces or nested client Spaces
- Each person’s Ask Gideon chats stay **private** to them
- Revoke anytime from Manage access

## 5-minute script once Clark is in

1. Space home / welcome chips  
2. Ask: *What do we know about Kendall Capital?*  
3. Ask: *How are fees described?* (should cite Form ADV)  
4. Open Files → Form ADV → glance analysis summary  
5. Optional: show a website page file vs ADV for fees (disclosures win)
